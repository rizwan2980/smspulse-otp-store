SMSPulse Reseller API Documentation

Integrate our virtual number and SMS receiving services into your automated bots and applications.

1. Buy Virtual Number

POST /api/orders/buy 
{
  "serviceId": "whatsapp",
  "countryId": "england",
  "operator": "any"
}

2. Check Order & Receive SMS Code

GET /api/orders/:orderId

Poll every 3 seconds until status is RECEIVED and smsList contains the verification code.

3. Cancel Order (Instant Auto-Refund)

POST /api/orders/:orderId/cancel
