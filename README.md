# SMS OTP Store — Reseller Platform

یہ ایک مکمل **SMS OTP اور ورچوئل نمبرز ری سیلنگ پلیٹ فارم (Reseller Platform)** کا پروجیکٹ ہے۔

---

## 🎯 پروجیکٹ کا تعارف (Project Overview)
یہ ویب سائٹ صارفین کو مختلف ممالک (مثلاً US, Bolivia, UK وغیرہ) اور مختلف ایپس (WhatsApp, Telegram, Facebook, TikTok, Dola AI وغیرہ) کے لیے ورچوئل فون نمبرز اور لائیو OTP ویریفکیشن کوڈز فراہم کرے گی۔

* **بزنس ماڈل:** API Reseller (5SIM / SMS-Activate API)
* **پیمنٹ سسٹم:** EasyPaisa, JazzCash (مینوئل اپروول) اور Binance USDT
* **ہوسٹنگ خرچہ:** بالکل مفت (Free on Vercel / Render)

---

## 🏗️ سسٹم آرکیٹیکچر (System Architecture)

### 1. یوزر پینل (User Dashboard)
* **اکاؤنٹ رجسٹریشن اور لاگ ان:** محفوظ پاس ورڈ اور سیشن۔
* **والٹ (Wallet):** کسٹمر کا PKR بیلنس، جمع شدہ رقوم اور ٹرانزیکشن ہسٹری۔
* **ڈپازٹ فنڈز (Deposit Funds):** 
  * JazzCash اور EasyPaisa کے ذریعے پیمنٹ بھیج کر TID / ٹرانزیکشن آئی ڈی اور اسکرین شاٹ سبمٹ کرنے کا فارم۔
  * ایڈمن کے منظور (Approve) کرتے ہی والٹ میں بیلنس کا اضافہ۔
* **نمبر خریدنا (Buy Number):** 
  * ملک اور سروس منتخب کرنے کا خوبصورت اور تیز رفتار انٹرفیس۔
  * لائیو اسٹاک اور قیمت دکھانا (آپ کے مقرر کردہ نفع / Margin کے ساتھ)۔
* **لائیو او ٹی پی باکس (Live OTP Receiver):**
  * کاپی ایبل نمبر۔
  * 15 سے 20 منٹ کا الٹی گنتی ٹائمر (Countdown Timer)۔
  * جیسے ہی کوڈ آئے، آواز اور اینیمیشن کے ساتھ اسکرین پر لائیو شو ہونا۔
  * اگر وقت کے اندر کوڈ نہ آئے تو Cancel یا آٹو ریفنڈ کے ذریعے پیسے کسٹمر کے والٹ میں خود بخود واپس۔

### 2. ایڈمن پینل (Admin Dashboard)
* **ڈپازٹ مینجمنٹ:** کسٹمرز کی بھیجی گئی رقوم (TID / Proof) کی تصدیق اور 1 کلک میں اپروو/ریجیکٹ کرنا۔
* **قیمتوں اور منافع کا کنٹرول:** 5SIM / SMS-Activate کے ریٹس پر اپنا نفع (مثلاً 50% یا 100% منافع) سیٹ کرنا۔
* **API کنفیگریشن:** اپنی 5SIM یا SMS-Activate کی خفیہ API Key درج کرنا۔
* **یوزرز لسٹ:** تمام صارفین کے بیلنس اور آرڈرز کی مانیٹرنگ۔

## 🛠️ ٹیکنالوجی اسٹیک (Tech Stack)
* **Frontend:** Modern Vanilla HTML5, CSS3 (ڈارک اور لائٹ موڈ، رسپانسو، موبائل فرینڈلی)، JavaScript (ES6+).
* **Backend:** Node.js + Express.js (ہلکا، تیز اور بغیر کسی فالتو بوجھ کے).
* **Database:** SQLite / LowDB (شروع کے لیے) یا MongoDB Atlas / Supabase (کلاؤڈ کے لیے، بالکل مفت).
* **Deployment:** Vercel / Render (100% مفت لائیو سب ڈومین کے ساتھ).
